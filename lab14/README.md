# Лабораторная работа #14
Задание ЛР

Оценка 3: 
1) Создать структуру узла, состоящего из и указателя на следующий узел. 
В качестве данных взять структуру из прошлой практической либо 
предлагаемую (уровень/комната Roguelike игры): 
struct room { 
char name[50]; // имя комнаты  
int level;           
// уровень/сложность комнаты 
int number;       
// номер комнаты 
int resolution;   // размер комнаты 
} 
2) Написать функции: по добавлению узла в конец односвязного списка и 
вывод списка на экран 
3) Создать односвязный список из n элементов, заполненных 
случайными данными. Вывести список на экран. N – вводить с 
клавиатуры/аргументами main. 

Оценка 4: 
4) Добавить в структуру узла указатель на структуру. Добавить в 
функцию создания узла инициализацию этого указателя. 
5) Реализовать двусвязный список согласно одному из вариантов ниже. 
Добавить указатель S на начало списка. 
6) Добавить интерфейс с вводом с клавиатуры кнопок WASD или цифр 
2,4,6,8 для прохода по списку. При перемещении выводим 
информацию о текущем узле. Если перемещение невозможно – 
выводим на экран сообщение. 
Например: начинаем с S, выводим на экран текущее значение, вводим 
‘D’ (или ‘6’) – выполняем перемещение вправо по списку на один 
элемент если это возможно, в противном случае сообщить, что 
достигли конца списка и предложить вернуться в начало списка в 
позицию S (начало).
