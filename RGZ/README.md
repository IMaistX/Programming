# РГЗ: Шифр столбцовой перестановки

## Задание
Разработать программу `Perestanovka` (шифрование) и `DePerestanovka` (дешифровка). Буквы ключевого слова без повторений записываются в первую строку таблицы, определяя количество столбцов. Буквы сообщения записываются в таблицу построчно. Затем столбцы сортируются по порядку следования букв ключа в алфавите, и шифротекст выписывается по столбцам. Дешифровка выполняется обратными преобразованиями.

---

## Что было сделано в проекте
1. **Ядро алгоритма (`shifr.c`, `shifr.h`)**: Реализованы функции очистки ключа от дубликатов (`CleanKey`), определения алфавитного порядка столбцов (`SortKey`), а также сами алгоритмы шифрования и расшифрования. Добавлена функция оценки криптостойкости ключа.
2. **Динамическая библиотека**: Весь код шифрования вынесен в отдельную динамическую библиотеку (`.so` / `.dll`), которая собирается независимо от основного интерфейса.
3. **Файловый ввод/вывод (`main.c`)**: Программа полностью автоматизирована и считывает параметры из конфигурационного файла в формате `KEY=VALUE`, а результаты работы сохраняет в файлы на диске. Добавлена защита от пустого ввода и строк из одних пробелов.
4. **Unit-тесты (`test.c`)**: С помощью криптографического фреймворка `CMocka` написаны автоматические тесты для проверки корректности работы каждой функции.
5. **Автоматизация сборки (`CMakeLists.txt`)**: Настроен конфигурационный файл CMake для быстрой сборки всего проекта одной командой.

---

## Структура проекта
* `shifr.h` / `shifr.c` — Исходный код динамической библиотеки шифрования.
* `main.c` — Главная программа (чтение конфига, запуск шифрования, запись результатов).
* `test.c` — Модульные тесты на фреймворке CMocka.
* `config.txt` — Файл конфигурации с входными данными.
* `CMakeLists.txt` — Скрипт сборки для CMake.

---

## Инструкция по сборке и запуску

### 1. Подготовка входных данных
Перед запуском убедитесь, что в корне проекта создан файл `config.txt` с параметрами. Пример содержимого:
```text
TEXT=Hello World
KEY=BANANA
```

### 2. Сборка проекта через CMake
Сборка выполняется стандартным для Linux способом в отдельной папке `build`:
```bash
mkdir build
cd build
cmake ..
make
```

### 3. Запуск тестов
Чтобы проверить правильность работы функций библиотеки, запустите скомпилированные тесты из папки `build`:
```bash
./unit_tests
```

### 4. Запуск основной программы
```bash
./program
```

### 5. Результаты работы
После запуска программы в папке build автоматически создадутся два файла с результатами:
* `encrypted.txt` — зашифрованный текст.
* `decrypted.txt` — успешно восстановленный исходный текст.
